## Project Overview

This project was developed as part of the **COP3808C** course at Broward College.

The submission explores the principles of web design through the CSS Zen Garden challenge, demonstrating how CSS can transform the visual presentation of a webpage while preserving its underlying HTML structure.

For my CSS Zen Garden submission, I want to explore CSS animations and interactive design. Inspired by my appreciation for classic 8-bit video games, the webpage will feature an animated, pixel-art garden that resembles an idle RPG.

The goal is to create an engaging environment where animated sprites, environmental effects, and interactive menus bring the webpage to life while maintaining the original HTML structure.

Due to the scope of time and my lack of artistic skill, I will be outsourcing my sprite and tile asset to two downloadable Minifantasy sprite kits from [Krishna Palacio](https://krishna-palacio.itch.io/). While the art is not mine, I will use my own CSS code to render and animate these sprites as if it were a videogame environment.

### Endless RPG VideoGame Loop Simulation
Our charter enters the scene. An endless loop animation begins where our character walks around the garden and fights certain mobs before looping over the process again. To render the other content of the HTML page, the user will be able to see a 4 option pokemon game style menu. Depending on their choice, the content info is now displayed as the secondary menu.
